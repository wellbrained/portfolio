## The idea

Projects tend to leave a trail of notes, tasks and half-formed ideas. The challenge is often less about collecting them and more about finding the next useful step when returning to a project.

CoreHub brings projects, thoughts and todos into one place. Each project can have a clear next action, so the overview helps answer a practical question: what should I work on next?

## From idea to a useful tool

::section-note
01 / Approach
::

The starting point was simple: make it easier to see what is running, what needs attention and where the work left off. Project pages keep notes and next steps beside the practical details needed to pick up the work.

> ### Keep the next step visible
>
> Give each project a home for its notes and one clear next action. The interface should help decide what to do next.

Projects and notes are stored in SQLite. The interface uses Nuxt and TypeScript, with a focus on readable information and direct actions.

## A few decisions that shaped it

- Keep thoughts and todos close together, while giving tasks a clear state.
- Let a project point to one next action instead of adding another priority system.
- Keep useful context on the project page so resuming work needs fewer steps.

## What changed

::section-note
02 / Outcome
::

The project creates a shared place for work that would otherwise be spread across folders and loose notes. This sample case study describes the direction rather than claiming measured results.

The most useful next additions to this story would be screenshots, an example of a real workflow and a reflection on the parts that were changed after using it.

## What I learned

A project manager can become a project of its own very quickly. Starting with one clear next action is a way to keep the interface grounded in the work it is meant to support.
